🎯 CareerSphere – AI Powered Career Roadmap & Resume Builder Platform

CareerSphere is a full-stack AI-powered web application that helps students and beginners:

Discover suitable career paths

Generate a personalized AI-powered career roadmap

Create a professional resume dynamically based on their profile

It acts as a complete career companion — from exploration → planning → resume creation.
